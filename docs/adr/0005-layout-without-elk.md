# ADR-0005. Авто-раскладка без ELK.js

**Статус:** принято (заменяет предложенный в концепции ELK.js)

## Контекст

Нужна читаемая раскладка схем с вложенными зонами (площадки, стойки), в которой одинаковые компоненты соседних площадок стоят рядом, а связи
репликации — короткие. Шаблоны и ответы ИИ приходят без координат. Универсальные layered-раскладчики (ELK) оптимизируют пересечения рёбер, но
плохо учитывают смысл (связи репликации превращают в «слои», платформенные узлы уносят наверх), тяжёлые (≈ 1.5 МБ), а в закрытом CSP не могут
запускаться из Web Worker без `blob:`.

## Решение

Своя детерминированная раскладка (`frontend/src/editor/layout.ts`): ряд узла = глубина по связям-зависимостям (с разрывом циклов); узлы без
зависимостей встают по ряду связанных репликацией/бэкапом/кворумом, остальные — в нижний ряд; площадки — колонки одинаковой высоты,
в ряду не больше двух узлов, соседние площадки «зеркалят» порядок; глобальные узлы — полосой над или под площадками. Новые узлы без
координат занимают свободные ячейки своей зоны (`placeMissing`), остальное не двигается.

## Последствия

* Результат предсказуем и покрыт тестами (нет пересечений карточек, узлы внутри зон, детерминизм, идемпотентность).
* Раскладка не минимизирует пересечения рёбер; пользователь двигает узлы вручную, кнопка «Авто-раскладка» возвращает порядок.
* Библиотека ELK не нужна.
